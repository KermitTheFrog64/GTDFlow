# QueueUp — Task Management System

Fullstack web application for task management with authentication, roles and persistent storage.

---

## 🚀 Features

* User registration & JWT authentication
* Create / update / delete tasks (CRUD)
* Task priorities and deadlines
* REST API with Koa
* MySQL database with TypeORM
* Dockerized environment

---

## 🧰 Tech Stack

**Frontend:** React, TypeScript, Redux
**Backend:** Node.js, Koa
**Database:** MySQL, TypeORM
**DevOps:** Docker

---

## 🏗 Architecture

* Frontend: React SPA
* Backend: REST API (Koa)
* Database: relational schema (MySQL)
* Authentication: JWT
* Deployment: Docker containers
